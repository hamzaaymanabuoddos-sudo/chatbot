### 2. Integration of the RAG (2 points)

#### 2.1 Connecting RAG Technique ✅

**RAG Pipeline Implementation:**

File: `rag.py` - Function: `query_rag()` (lines 283-330)

**RAG Steps:**
```
1. User Query
   ↓
2. Detect Language (Arabic/English)
   ↓
3. Generate Query Embedding (retrieve_relevant_docs)
   ↓
4. Search MongoDB (Hybrid: Semantic + Keyword)
   ↓
5. Retrieve Top-K Documents (default: 8 documents)
   ↓
6. Construct Prompt with Context
   ↓
7. Send to LLM (Gemini)
   ↓
8. Generate Answer with Citations
   ↓
9. Return Response with Sources
```

**Key Features:**
- **Hybrid Search:** 70% Semantic + 30% Keyword matching
- **Query Expansion:** Synonyms in Arabic & English
- **Multi-source synthesis:** Combines information from multiple documents

**Evidence in Code:**
```python
def query_rag(col, query: str, ...):
    # Step 1: Detect language
    query_lang = detect_language(query)

    # Step 2: Retrieve with hybrid search
    relevant_docs = retrieve_relevant_docs(col, query, top_k, min_score)

    # Step 3: Construct prompt
    rag_prompt = construct_prompt(query, relevant_docs, query_lang)

    # Step 4: Generate answer
    answer = generate_answer(rag_prompt)

    return response
```

### 3. LLM Query Flow (2 points)

#### 3.1 Check DB then Prompt LLM ✅

**Our Implementation:** ✅ **DB-First Approach**

**Flow Diagram:**
```
User Query
    ↓
┌─────────────────────┐
│  1. Check Database  │
│  (retrieve_relevant_│
│   docs)             │
└─────────────────────┘
    ↓
Has relevant docs?
    ├─ Yes → Continue
    └─ No → Return "No data found"
    ↓
┌─────────────────────┐
│  2. Build Prompt    │
│  with Retrieved     │
│  Context            │
└─────────────────────┘
    ↓
┌─────────────────────┐
│  3. Send to LLM     │
│  (Gemini)           │
└─────────────────────┘
    ↓
┌─────────────────────┐
│  4. Return Answer   │
│  with Citations     │
└─────────────────────┘
```

**Evidence in Code:**
```python
def query_rag(col, query: str, ...):
    # STEP 1: Check database FIRST
    relevant_docs = retrieve_relevant_docs(col, query, top_k, min_score)

    # STEP 2: If no documents found, return early (don't call LLM)
    if not relevant_docs:
        return {
            "answer": "No information found in database",
            "sources": []
        }

    # STEP 3: Only now, construct prompt and call LLM
    rag_prompt = construct_prompt(query, relevant_docs, query_lang)
    answer = generate_answer(rag_prompt)

    return response
```

**Why DB-First?**
- ✅ More efficient (no unnecessary LLM calls)
- ✅ Authoritative data only
- ✅ Cost-effective
- ✅ Security (LLM can't hallucinate without data)
